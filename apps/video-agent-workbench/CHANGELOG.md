# Changelog

## 1.2.1 — 2026-07-27

- GitHub 中台恢复原工作台界面和视频上传入口。
- 本地引擎允许受控的 GitHub Pages 跨域连接，公开工作台可调用本机上传、剪辑和生成 API。

## 1.2.0 — 2026-07-27

- 接入本机 MiniMax Voice Clone Skill，支持上传本人声音并创建专属音色。
- 自动载入已验证的颜汝 Moss 个人音色，并接入真实视频配音。
- 新增四个真实逐帧动效 Skill：稳重原片、智能轻推镜、呼吸聚焦、节奏冲击。
- 新增声音授权门、样本格式/大小/时长验证、费用提示和音色资料库。
- 修复轻推镜缩放不累计的问题，并用静态源连续帧重新验收。

## 1.0.0 — 2026-07-26

- 新增三栏深色霓虹视频工作台。
- 新增本地视频上传和绝对路径读取。
- 新增 Whisper AI 转写。
- 新增基于静音检测的自动剪辑。
- 新增 Edge Neural TTS 配音及 macOS 声音降级。
- 新增字幕、封面、竖屏 MP4、任务日志和下载。
