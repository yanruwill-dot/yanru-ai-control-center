# Changelog

## 1.5.1 — 2026-07-28

- 修复公开工作台在嵌入页、窄屏和手机宽度下的横向溢出与卡片挤压。
- 中等宽度改为稳定双栏，生成控制台横跨整行，封面与成片左右排列。
- 为样式和脚本增加版本参数，避免 GitHub Pages 继续读取旧缓存。

## 1.5.0 — 2026-07-27

- 删除独立“动效 Skill”面板，镜头运动改为随剪辑模板自动匹配。
- 新增剪映清透标题、开拍老板观点、开拍故事叙述三套真实渲染模板，共八套。
- 工作台改为克制的苹果式深色界面：单一蓝色重点、系统字体、玻璃面板和更紧凑的信息层级。
- 标题片头同步改为简洁玻璃卡片，不再使用霓虹描边。

## 1.4.1 — 2026-07-27

- 新增 macOS LaunchAgent 长期连接，登录自动启动、异常退出自动恢复。
- GitHub Pages 无连接参数时自动回连 `127.0.0.1:8788`，不再要求每次手动运行桌面启动器。
- 桌面 App 改为安装或修复长期引擎后打开本机工作台。
- 临时 HTTPS 隧道迁移到 8789，避免与长期引擎冲突。

## 1.4.0 — 2026-07-27

- 新增一键 HTTPS 在线启动与停止脚本。
- 新增随机访问密钥和严格的 GitHub Pages CORS。
- GitHub 页面从 URL fragment 读取 HTTPS 引擎地址，不再默认请求失效的 localhost。
- 新增 Docker、Linux 中文字体和云服务器运行配置。
- 修正“系统已就绪”的误导性静态日志。

## 1.3.0 — 2026-07-27

- 研究 GitHub 上 Remotion TikTok Template、Short Video Maker、Auto-Editor 和 MoneyPrinterTurbo 的公开剪辑实现。
- 在自动剪辑面板新增五套模板：经典口播、剪映感大字弹跳、开拍感口播重点、卡点快切冲击字幕、知识口播关键词高亮。
- 大字模板真实进入 FFmpeg 成片，支持粗描边、自动重点词着色、弹入、轻推和冲击缩放。
- 剪辑模板与镜头动效保持独立，可自由组合。

## 1.2.1 — 2026-07-27

- GitHub 中台恢复原工作台界面和视频上传入口。
- 本地引擎允许受控的 GitHub Pages 跨域连接，公开工作台可调用本机上传、剪辑和生成 API。

## 1.2.0 — 2026-07-27

- 接入本机 MiniMax Voice Clone Skill，支持上传本人声音并创建专属音色。
- 自动载入已验证的颜汝 Moss 个人音色，并接入真实视频配音。
- 新增四个真实逐帧动效 Skill：稳重原片、智能轻推镜、呼吸聚焦、节奏冲击。
- 新增声音授权门、样本格式/大小/时长验证、费用提示和音色资料库。
- 修复轻推镜缩放不累计的问题，并用静态源连续帧重新验收。

## 1.0.0 — 2026-07-26

- 新增三栏深色霓虹视频工作台。
- 新增本地视频上传和绝对路径读取。
- 新增 Whisper AI 转写。
- 新增基于静音检测的自动剪辑。
- 新增 Edge Neural TTS 配音及 macOS 声音降级。
- 新增字幕、封面、竖屏 MP4、任务日志和下载。
