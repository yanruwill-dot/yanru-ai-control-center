# Changelog

## 1.3.0 — 2026-07-27

- 研究 GitHub 上 Remotion TikTok Template、Short Video Maker、Auto-Editor 和 MoneyPrinterTurbo 的公开剪辑实现。
- 在自动剪辑面板新增五套模板：经典口播、剪映感大字弹跳、开拍感口播重点、卡点快切冲击字幕、知识口播关键词高亮。
- 大字模板真实进入 FFmpeg 成片，支持粗描边、自动重点词着色、弹入、轻推和冲击缩放。
- 剪辑模板与镜头动效保持独立，可自由组合。

## 1.2.1 — 2026-07-27

- GitHub 中台恢复原工作台界面和视频上传入口。
- 本地引擎允许受控的 GitHub Pages 跨域连接，公开工作台可调用本机上传、剪辑和生成 API。

## 1.2.0 — 2026-07-27

- 接入本机 MiniMax Voice Clone Skill，支持上传本人声音并创建专属音色。
- 自动载入已验证的颜汝 Moss 个人音色，并接入真实视频配音。
- 新增四个真实逐帧动效 Skill：稳重原片、智能轻推镜、呼吸聚焦、节奏冲击。
- 新增声音授权门、样本格式/大小/时长验证、费用提示和音色资料库。
- 修复轻推镜缩放不累计的问题，并用静态源连续帧重新验收。

- 新增三栏深色霓虹视频工作台。
- 新增本地视频上传和绝对路径读取。

- 新增基于静音检测的自动剪辑。
