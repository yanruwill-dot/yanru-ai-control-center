# 颜汝 AI 自动化中控台

这是 `agent-kanban-system` 的 GitHub Pages 静态发布版本，用于长期访问。

## 入口

- `index.html`：中控台主页面
- `outputs/html/wechat-output.html`：公众号高级排版
- `outputs/html/xhs-output.html`：小红书高级排版
- `outputs/html/strategy-plan.html`：整体方案流水线

## 发布边界

本仓库只包含可公开查看的静态页面和素材。真实发布代理 `publish-agent-server.mjs`、本地日志、发布包、密钥环境文件不会上传到 GitHub。
